# Keenetic Geosite Sync

Команда для KeeneticOS 5 с Entware. Синхронизирует группы в разделе **Маршруты DNS** со списками v2fly/domain-list-community и текстовыми файлами по HTTPS. Поддерживает домены, IP-адреса и подсети. Сохраняет существующие маршруты при обновлении групп и разбивает большие списки на части с подписями `Youtube 1`, `Youtube 2` и так далее. [Списки v2fly](https://github.com/v2fly/domain-list-community)

## Установка и обновление

Команды выполняются в SSH-терминале Entware на роутере. Доступны пакеты для ARM64 (`aarch64-3.10`) и MIPS LE (`mipsel-3.4`). Архитектуру можно посмотреть командой `opkg print-architecture`.

Добавьте репозиторий и установите пакет.

```sh
mkdir -p /opt/etc/opkg
echo 'src/gz kgs https://aaeremin02.github.io/keenetic-geosite-sync/all' > /opt/etc/opkg/kgs.conf
opkg update
opkg install keenetic-geosite-sync
```

Пакет устанавливает команду в `/opt/bin/keenetic-geosite-sync` и подтягивает `ca-bundle` для проверки HTTPS-сертификатов.

Для ручной установки скачайте `.ipk` под свою архитектуру и скопируйте в `/opt/tmp`. Подставьте имя скачанного файла в команду. [Скачать пакет в GitHub Releases](https://github.com/aaeremin02/keenetic-geosite-sync/releases/latest)

```sh
opkg update
opkg install "/opt/tmp/ИМЯ_ФАЙЛА.ipk"
```

Для обновления через репозиторий выполните следующие команды.

```sh
opkg update
opkg upgrade keenetic-geosite-sync
```

`opkg` сохраняет изменённый пользователем `config.json`.

## Настройка

Пакет создаёт `/opt/keenetic-geosite-sync/config.json` с содержимым `{}`. Добавьте списки, которыми должна управлять команда. Пример синхронизирует YouTube, Google Play и IPv4-подсети Telegram.

```json
{
  "routeInterface": "Wireguard0",
  "ipv6": false,
  "lists": [
    {
      "source": "v2fly",
      "lists": ["youtube", "google-play"]
    },
    {
      "source": "plain",
      "name": "Подсети Telegram",
      "url": "https://core.telegram.org/resources/cidr.txt"
    }
  ]
}
```

Если хотите добавлять недостающие DNS-маршруты, укажите в `routeInterface` имя интерфейса на своём роутере. Одна настройка интерфейса применяется ко всем спискам. Команда сохраняет существующие маршруты и добавляет маршрут через указанный интерфейс, если его ещё нет.

### Источники списков

- **`v2fly`** загружает файлы из официального репозитория v2fly. В массиве `lists` указываются имена файлов. Подпись группы получается из имени списка, например `youtube` становится `Youtube`. Поддерживаются вложенные `include:` и фильтры по атрибутам. Правила `keyword` и `regexp` пропускаются.
- **`plain`** загружает текст по полному HTTPS-адресу из `url`. В `name` указывается подпись группы. Файл должен содержать по одному домену, IP-адресу или CIDR на строку. Пустые строки и комментарии после `#` пропускаются.

| Поле                 | Назначение                                                       |
| -------------------- | ---------------------------------------------------------------- |
| `lists`              | Источники и списки, которыми управляет программа.                |
| `prefix`             | Префикс внутренних имён групп. По умолчанию `domain-list`.       |
| `routeInterface`     | Интерфейс для добавления недостающих DNS-маршрутов.              |
| `maxEntriesPerGroup` | Максимум записей в одной группе от 1 до 300. По умолчанию 300.   |
| `timeoutMs`          | Таймаут загрузки на одну попытку. По умолчанию 20 000 мс.        |
| `retries`            | Число попыток загрузки. По умолчанию 3.                          |
| `ipv6`               | Включать IPv6-адреса и подсети из `plain`. По умолчанию `true`.  |
| `dryRun`             | При `true` команды работают в режиме предварительного просмотра. |

При `ipv6: false` явно перечисленные IPv6-адреса и подсети исключаются из результата. Синхронизация удалит такие записи, если они уже есть в управляемой группе. Если после фильтрации список пуст, команда завершится с ошибкой до применения изменений.

## Синхронизация

Посмотрите план, затем примените его.

```sh
keenetic-geosite-sync sync --dry-run
keenetic-geosite-sync sync
```

Команда ищет существующую группу по подписи и префиксу. Если группы ещё нет, она появится при применении. С пустым `lists` команда выводит `No domain lists selected`.

Для запуска с другим конфигом используйте `sync --config /путь/к/config.json`. При ошибке команда сообщает, сколько операций успело выполниться, и возвращает ненулевой код. Перед повтором посмотрите план по текущему состоянию роутера через `sync --dry-run`.

## Запуск по расписанию

Установите `cron` в Entware и создайте каталог для журнала.

```sh
opkg install cron
mkdir -p /opt/var/log
```

Эта запись в `/opt/etc/crontab` запускает синхронизацию по субботам в 04:00.

```cron
0 4 * * 6 /opt/bin/keenetic-geosite-sync sync
```

В журнал дописываются план, результат и ошибки каждого запуска. CLI блокирует одновременное применение из cron и терминала.

## Очистка и удаление пакета

Чтобы удалить управляемые группы, сначала проверьте план.

```sh
keenetic-geosite-sync clean --dry-run
keenetic-geosite-sync clean --apply
```

Очистка затрагивает группы из `lists` внутри настроенного префикса. Вместе с группой могут быть удалены связанные DNS-маршруты.

Для удаления самой команды из Entware выполните `opkg remove keenetic-geosite-sync`.
